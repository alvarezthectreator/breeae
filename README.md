# breeae

A static Revolut homepage recreation.

## Preview locally

From the repository root, run:

```sh
python3 -m http.server 5500
```

Open `http://127.0.0.1:5500/` in a browser. The root page forwards to the saved homepage at `www.revolut.com/index.html`.

The repository includes the homepage and its published site assets. Browser capture data for app, sign-in, analytics, and third-party services is excluded.
